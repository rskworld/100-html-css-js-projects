# Dynamic Analog & Digital Clock

A beautiful, premium, and interactive clock built with HTML, CSS, and JavaScript. The clock features both analog hands and a digital time display, along with a date tracker and a dynamic theme that smoothly transitions colors every second.

## ✨ Features
- **Analog & Digital Display**: View time in both classic analog and modern digital formats.
- **Dynamic Random Colors**: The clock theme, background, and accents gracefully transition to random vibrant colors every second while maintaining perfect legibility.
- **Dark & Light Mode**: Seamlessly toggle between dark and light themes. The dynamic colors adjust their brightness to ensure high contrast in both modes.
- **Glassmorphism Design**: Premium UI aesthetics using glassmorphism effects (blurs, transparencies, and smooth gradients).
- **Floating Orbs**: Ambient background animations to give the clock a lively feel.

# JavaScript Premium Calculator

A beautifully designed, fully responsive, and feature-rich JavaScript calculator inspired by the modern iOS calculator interface. 

Built with vanilla JavaScript, HTML5, and CSS3, this project demonstrates a clean architecture with zero external dependencies, perfect for learning and extending.

## ✨ Features

- **Premium iOS Aesthetics:** Smooth rounded buttons, pill-shaped elements, and high-contrast vibrant colors.
- **Fluid Responsiveness:** Utilizes CSS Grid, Flexbox, and smart `aspect-ratio` properties to scale flawlessly across any screen size.
- **Real Calculator Logic:** Retains the current number on the screen while calculating and features a dynamic top-history screen to track your active equation.
- **Memory Functions:** Fully functional `M+`, `M-`, and `MRC` memory states with visual flash feedback.
- **Advanced Math:** Supports square root (`√`), percentage (`%`), and positive/negative toggling (`±`).
- **Zero Dependencies:** Pure Vanilla JavaScript. No jQuery or external libraries required.

## 🚀 How to Run

Since this is a pure frontend project, no build tools or servers are necessary!

1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser.
3. Start calculating!
